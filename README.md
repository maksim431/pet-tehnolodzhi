# ПЭТ-Технолоджи — концепт главной страницы

Вёрстка концепта новой главной страницы федеральной сети «ПЭТ-Технолоджи» (pet-net.ru) по макету в Figma.

- Статичная страница: `index.html` + `assets/styles.css`, без сборки и без анимаций.
- Адаптив: десктоп 1920, ноутбук, планшет, мобильный от 360 px.
- Шрифт Wix Madefor Display подключается с Google Fonts.

Дизайн и вёрстка: Максим Кощеев, [uxuidesign.ru](https://uxuidesign.ru)
